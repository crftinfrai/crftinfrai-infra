# Security

Please do not submit vulnerabilities, leaked credentials, or other security
issues through public GitHub Issues or pull requests.

Use GitHub Private Vulnerability Reporting for this repository when it is
enabled. This is the preferred reporting mechanism and keeps disclosures
private while they are investigated.

Repository maintainers must manually enable GitHub Private Vulnerability
Reporting in the repository's Settings after the repository is created.
Until it is enabled, use the private contact or disclosure process provided
by the repository maintainers; do not use public issues.

If a credential may have been exposed, revoke or rotate it immediately and preserve only the minimum sanitized evidence needed for private investigation.
